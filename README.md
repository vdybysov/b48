# B48

Битрикс24 в браузере, но тёмный, с Markdown и повадками Слака.

Расширение для Chrome. Работает поверх обычного портала `*.bitrix24.ru` / `.com` / `.by` / `.kz` / `.de` / `.eu`, ничего никуда не отправляет, всё хранит в браузере.

## Что умеет

**Тёмная тема на весь портал.** Мессенджер, задачи, списки, карточки, меню, попапы. В Битриксе уже лежит тёмный набор токенов, который мессенджер не включает: B48 его включает, а сотни захардкоженных светлых цветов и градиентов перекрашивает сам, по CSS. Результат кэшируется, белых вспышек при загрузке нет. Обои портала убраны, левое меню свёрнуто, кнопки тарифа и BitrixGPT приглушены.

**Markdown.** Пишете `**жирный**`, `# заголовок`, списки, таблицы, ```код``` — видите нормальное форматирование. На сервер уходит BBCode, поэтому коллеги без расширения видят то же самое, а таблицы и код у них остаются ровными: колонки выровнены неразрывными пробелами. При правке своего сообщения BBCode возвращается в Markdown.

**Вставка с форматированием.** Скопировали ответ из Claude, кусок кода из Cursor или таблицу из Google Docs, вставили в чат, форматирование осталось.

**Папки «Личные» и «Чаты»** сразу после «Все»: люди отдельно, группы отдельно, со счётчиками. Серый счётчик — непрочитанное только в заглушённых.

**«Отложить на потом».** Пункт в меню сообщения, закладка при наведении или клавиша **L**. Список в папке «Потом».

**Тихое чтение.** Пока не нажмёте двойную галочку в шапке чата, собеседник не узнает, что вы прочитали. Выключено по умолчанию. Телефон и десктоп-клиент под это не подпадают: они отмечают прочтение сами.

**Приложение «Битрикс24».** Установите портал как приложение Chrome: отдельное окно, тёмный заголовок, старт сразу в мессенджере и число непрочитанных на иконке в Dock.

## Установка

1. `git clone` в постоянную папку.
2. `chrome://extensions` → «Режим разработчика» → «Загрузить распакованное» → выбрать папку с `manifest.json`.
3. Открыть `https://<портал>.bitrix24.ru/online/`.
4. По желанию: значок установки в адресной строке → «Установить Битрикс24».

Обновление: `git pull` и ↻ у B48 на `chrome://extensions`.

## Настройки

В окне расширения, значок B48 на панели Chrome.

| | По умолчанию |
|---|---|
| Тёмная тема | вкл. |
| Показывать Markdown | вкл. |
| Отправлять Markdown как BBCode | вкл. |
| Тихое чтение | выкл. |

Тема переключается сразу, остальное после перезагрузки вкладки.

## Устройство

| Файл | |
|---|---|
| `src/theme.js` | Тёмные токены Битрикса + автозатемнение CSS портала, кэш в `localStorage` |
| `src/theme.css` | Ручные правки темы, стили Markdown и панелей |
| `src/md.js` | Markdown ⇄ BBCode, Markdown → HTML через родной парсер |
| `src/paste.js` | HTML из буфера → Markdown |
| `src/main.js` | Перехваты мессенджера: рендер, отправка, правка, тихое чтение, вставка, манифест приложения, бейдж |
| `src/later.js` | Папки «Личные», «Чаты», «Потом» |
| `src/bridge.js` | Настройки → атрибуты `<html data-b48-*>` |
| `src/background.js` | Перезагрузка с диска при разработке |

B48 встраивается в код Битрикса: перехватывает парсер `BX.Messenger.v2.Lib.Parser`, сервисы отправки и чтения. Если после обновления Битрикса что-то не найдётся, расширение откатывается на родное поведение. Логи в консоли с префиксом `[b48]`.

**Безопасность.** Текст сообщений всегда идёт через родной парсер Битрикса, который экранирует HTML; B48 добавляет только свою разметку с экранированным содержимым. Вставка разбирает HTML в изолированном документе без скриптов, ссылки только `http(s)` и `mailto`. Права: только `storage`.

**Разработка.** `window.postMessage({ type: 'b48:dev-reload' }, '*')` на странице портала перечитывает распакованное расширение с диска.
